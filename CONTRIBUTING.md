# Contributing

Thanks for your interest in the **GangaDrishthi** microplastic-detection project!
This repository hosts the project website and supporting materials.

## Ways to contribute

- **Report issues** — spot a typo, broken link, or rendering bug? Open an issue.
- **Suggest improvements** — ideas for the website content, accessibility, or design.
- **Submit fixes** — small fixes are welcome via pull request.

## Development

The site is a static website — plain HTML, CSS, and vanilla JavaScript with no
build step.

```bash
# clone, then serve locally
python -m http.server 8000
# open http://localhost:8000
```

## Pull request guidelines

1. Fork the repository and create a branch from `main`.
2. Keep changes focused and described clearly.
3. Test your change locally before submitting.
4. Open a pull request against `main`.
